## Pembaruan sec-0.2

Baris A-01 sampai A-12 di atas tidak diubah (menggambarkan kondisi sec-0.1). Perubahan sejak itu:

- A-03 (penyimpanan berkas PDF regulasi): kini berjalan di VM sebagai volume Docker kyrion-storage yang dapat ditulis container app (UID 10001).
- A-08 (basis data utama): kini PostgreSQL 18.6 di container kyrion-vm-db-1 dengan volume kyrion-pgdata, tanpa port ke host, pada jaringan backend internal.
- A-09 (kredensial admin dan token sesi): kata sandi disimpan sebagai hash scrypt (bukti: security/bukti/hash-kata-sandi.txt); sesi disimpan di memori proses aplikasi sehingga hilang saat restart (bukti: security/bukti/access-admin-restart.txt).
- A-10 (kunci rahasia lingkungan): di VM, nilai konfigurasi rahasia disimpan di /srv/kyrion/env/ dan /srv/kyrion/secrets/, di luar repositori dan di luar image.
