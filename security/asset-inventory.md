## Pembaruan sec-0.2

Baris A-01 sampai A-12 di atas tidak diubah (menggambarkan kondisi sec-0.1). Perubahan sejak itu:

- A-03 (penyimpanan berkas PDF regulasi): kini berjalan di VM sebagai volume Docker kyrion-storage yang dapat ditulis container app (UID 10001).
- A-08 (basis data utama): kini PostgreSQL 18.6 di container kyrion-vm-db-1 dengan volume kyrion-pgdata, tanpa port ke host, pada jaringan backend internal.
- A-09 (kredensial admin dan token sesi): kata sandi disimpan sebagai hash scrypt (bukti: security/bukti/hash-kata-sandi.txt); sesi disimpan di memori proses aplikasi sehingga hilang saat restart (bukti: security/bukti/access-admin-restart.txt).
- A-10 (kunci rahasia lingkungan): di VM, nilai konfigurasi rahasia disimpan di /srv/kyrion/env/ dan /srv/kyrion/secrets/, di luar repositori dan di luar image.

## Pembaruan sec-0.3

Baris A-01 sampai A-16 di atas tidak diubah. Kondisi per 21 Nov 2026 (rilis v0.3, merge main 16acfdb). Bukti keadaan VM: security/bukti/v0.3-deploy-vm.txt. Aset baru berstatus Rancangan sampai kontrolnya terpasang; status diperbarui lagi di akhir sec-0.3. Kolom Kripto pada aset baru memakai "Ya (...)" atau "Tidak".

### Perubahan pada aset lama

- A-04 (metadata regulasi dan status versi): kini berupa tabel versions di PostgreSQL, dengan integrity_tag (HMAC) dan tanda tangan Ed25519 pada versi Sah. Status Berjalan.
- A-05 (riwayat dan log audit): tabel audit_logs berjalan dan mencatat empat aksi (UNGGAH_BERKAS, PENGESAHAN, PEMBATALAN, PENGHAPUSAN) dalam transaksi yang sama dengan perubahannya. Login gagal, pembuatan akun, dan penolakan pengesahan tidak tercatat (lihat T-21 di threat-model.md).
- A-07 (Server Actions dan endpoint server): kini berjalan di container app; akses admin ditegakkan lewat wajibAdmin dan jagaRoute.
- A-09 (kredensial login admin dan token sesi): tidak ada kata sandi sejak v0.3 (kolom users.password_hash dihapus). Kredensial kini kode OTP (disimpan sebagai hash di tabel verifications) dan sesi di tabel sessions (berlaku 7 hari). Keterangan hash scrypt pada pembaruan sec-0.2 tidak berlaku lagi sejak v0.3.
- A-10 (kunci rahasia lingkungan): di VM, nilai konfigurasi rahasia ada di /srv/kyrion/env/kyrion.env (izin 0600) dan masuk ke container lewat environment compose. Ini kondisi awal sec-0.3 yang diubah pada tahap kontrol (lihat R-11 di risk-register.md).
- A-13 (VM staging): belum ada firewall host (UFW nonaktif) pada kondisi awal sec-0.3.
- A-15 (image container): kyrion-web:hardened (4dfad4f15693) dan kyrion-web:tools (d406c2879e62) dibangun ulang untuk v0.3; tag cadangan v0.2-hardened dan v0.2-tools.
